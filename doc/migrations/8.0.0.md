# Migration guide: <8.0.0 to >=8.0.0

Since 8.0.0, arguments are formatted with the [sprintf](https://pub.dev/packages/sprintf) package instead of a homemade formatter.

## 1. Add `sprintf` to your dependencies

The generated code imports it, so your app needs it as a regular dependency:

```yaml
dependencies:
  sprintf: ^7.0.0
```

## 2. `%d` is an `int`, `%f` is a `double`

Before 8.0.0 `%d` generated a `num` parameter. It now generates an `int`, and `%f` generates a `double`:

```json
{
  "items": "You have %1$d items",
  "balance": "Your balance is %1$.2f"
}
```

```dart
// < 8.0.0
String items(num arg1);

// >= 8.0.0
String items(int arg1);
String balance(double arg1);
```

Update any translation that shows decimals to use `%f` (optionally with a precision such as `%.2f`), and pass the right type at the call sites.
