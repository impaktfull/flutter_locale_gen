# Migration guide: <7.0.0 to >=7.0.0

With version 7.0.0 of locale_gen the `BuildContext` no longer needs to be provided when accessing translations. There are two breaking changes.

## 1. Direct access to translations

You can now get translations directly from the `Localization` object without passing a `BuildContext`. So instead of:

```dart
Localization.of(context).translation;
```

you now do:

```dart
Localization.translation;
```

## 2. Initialising / changing the locale

Previously you would change the locale by replacing the `LocalizationDelegate` passed to your `MaterialApp`. Now you call `Localization.load(...)` directly. Instead of:

```dart
localeDelegate = LocalizationDelegate(
  newLocale: locale,
  localizationOverrides: customLocalizationOverrides,
);
```

you now do:

```dart
await Localization.load(
  locale: locale,
  localizationOverrides: customLocalizationOverrides,
);
```
